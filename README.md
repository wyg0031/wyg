# 人员管理系统

一个完整的人员管理系统，支持团员信息、活动记录和志愿者信息的管理。

## 功能特性

### 1. 登录/注册
- 使用身份证号码登录
- 通过注册码进行注册（由超级管理员生成）
- 支持超级管理员和普通用户两种角色

### 2. 首页仪表盘
- 团员人数统计
- 活动次数统计
- 志愿者人数统计
- 快捷功能入口

### 3. 团员信息管理
- 单个添加团员信息
- 批量上传团员信息（Excel格式）
- 搜索团员信息
- 导出团员信息（Excel格式）
- 删除团员信息

**批量上传表格格式：**
- 姓名、性别、身份证号、出生年月（如：20020330）、民族、手机号码、政治面貌、团员发展编号、入团时间（如：2015-03）

### 4. 活动记录管理
- 添加活动（名称、地点、开始/结束时间、时长自动计算、备注）
- 批量上传活动参与人员
- 查看活动参与人员
- 导出活动参与人员（Excel格式）
- 删除活动

**批量上传活动人员表格格式：**
- 活动名称、姓名

### 5. 志愿者个人信息管理
- 批量上传志愿者信息（Excel格式）
- 搜索志愿者信息
- 删除志愿者信息

**批量上传表格格式：**
- 姓名、性别、身份证号、出生年月、民族、手机号码、地址、志愿时长

### 6. 全局搜索
- 搜索团员、活动、志愿者信息
- 单项搜索支持导出Word文档
- 活动名称搜索支持导出参与人员表格

### 7. 账号管理
- 超级管理员可管理所有用户
- 普通用户只能修改自己的信息
- 生成和管理注册码

### 8. 关于系统
- 系统版本信息
- 版权信息

## 技术栈

- **后端：** Node.js + Express
- **数据库：** SQLite
- **前端：** HTML + CSS + JavaScript
- **文件处理：** Multer、XLSX、docx

## 安装步骤

### 1. 安装Node.js

访问 [Node.js官网](https://nodejs.org/) 下载并安装Node.js（建议安装LTS版本）。

### 2. 安装依赖

在项目目录下运行：

```bash
npm install
```

### 3. 启动服务器

```bash
npm start
```

服务器将在 http://localhost:3000 启动。

### 4. 访问系统

在浏览器中打开 http://localhost:3000

## 使用说明

### 团员信息批量上传

创建一个Excel文件，包含以下列：
- 姓名
- 性别
- 身份证号
- 出生年月（格式：20020330，系统会自动转换为2002年3月30日）
- 民族
- 手机号码
- 政治面貌
- 团员发展编号
- 入团时间（格式：2015-03，系统会自动转换为2015年3月）

### 活动参与人员批量上传

创建一个Excel文件，包含以下列：
- 活动名称
- 姓名

### 志愿者信息批量上传

创建一个Excel文件，包含以下列：
- 姓名
- 性别
- 身份证号
- 出生年月
- 民族
- 手机号码
- 地址
- 志愿时长

## 注意事项

1. 活动时间段不可跨越当天日期，如需跨越，请分多次添加
2. 活动时长自动计算，保留小数点后一位，不进行四舍五入
3. 删除操作不可恢复，请谨慎操作
4. 数据库文件（database.db）会自动生成，请勿手动删除

## 开发模式
